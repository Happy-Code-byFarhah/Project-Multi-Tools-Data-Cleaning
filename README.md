# Project Multi Tools Data Cleaning: Dirty Cafe Sales Dataset

A data cleaning project focused on transforming a messy Cafe Sales dataset into a cleaner and analysis-ready dataset. The dataset contains transaction-level information including transaction ID, item, quantity, price per unit, total spent, payment method, location, and transaction date.

### Key Data Cleaning Tasks

* Identified missing, `UNKNOWN`, `ERROR`, and blank values
* Standardized categorical, numerical, and date columns
* Recovered missing values using logical relationships between columns
* Mapped missing items based on price
* Reconstructed missing prices based on item
* Calculated missing quantity using Total Spent and Price Per Unit
* Recalculated missing Total Spent using Quantity and Price Per Unit
* Validated the relationship between Quantity × Price Per Unit and Total Spent
* Checked duplicate records and unique values
* Performed feature engineering by extracting Day and Month from transaction dates

### Tools

* Excel
* Power Query
* MySQL
* Python (Pandas & NumPy)

### Project Workflow

**Raw Data → Data Quality Check → Standardization → Missing Value Recovery → Data Validation → Feature Engineering → Clean Dataset**

The final dataset is prepared for further exploratory data analysis and visualization.
